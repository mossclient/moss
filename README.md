A free Minecraft: Java Edition launcher for Windows, built for low-end PCs.

## Features
- Sign in with your Microsoft account
- Minecraft 1.14 and up, with Fabric
- Performance mods installed for every version
- Build your own modpacks with mods from Modrinth

## Status
In development. First public release: late November 2026.
